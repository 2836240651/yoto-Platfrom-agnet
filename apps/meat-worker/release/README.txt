肉机助手 MeatWorker（可直接运行）
================================

本目录已含 Windows 可执行包，空闲机无需再打包。

1. 编辑同目录 config.json
   - worker_url   默认 https://www.yoto.work/platform-mcp
   - worker_token 与服务器 DOUYIN_WORKER_TOKEN 一致（勿提交真实 Token 到 git）
   - worker_id    如 闲置机-1

2. 双击 MeatWorker.exe

3. 托盘右键 →「登录蝉妈妈」→ 扫码/密码 → 图标变绿

要求：本机已装 Chrome（默认走系统 Chrome）。

源码与架构见上级目录 README.md 与 docs/wip/meat-worker-exe.md

# BOSS 抖音日期范围报表实施计划

## 目标

让 BOSS 抖音运营数据按用户选择的截止日期展示单日、近 7 天或近 30 天的真实汇总；没有完整数据时显示空态，不把不同口径数据混在一起。

## 契约核对

| 项目 | 结论 |
| --- | --- |
| BOSS 页面与只读 API | 已满足：`apps/web` 调用 `apps/api`，前端不直连数据库。 |
| MySQL `douyin_reports` 日报 | 已满足：`store_daily` 与 `product_transaction_daily` 覆盖 `20260622` 至 `20260722`，各 31 个日期。 |
| 视频日粒度 | 规范有、数据无：`video_daily` 当前仅有 `20260601-20260722` 一种统计口径，不能伪装成日/7/30 天视频榜。 |
| MCP / Skill / LLM | 不适用：固定只读 SQL 聚合，不新增 Tool、Skill、MCP 或 LLM 调用。 |

## 口径与空态

- `day`：截止日期当天的 `store_daily` 与 `product_transaction_daily`。
- `7d` / `30d`：截止日期向前含当天的连续 7 / 30 个自然日；所有日期均存在日报才返回汇总。
- 店铺指标与商品榜使用参数化 SQL 聚合；点击率按总点击 / 总曝光，点击转化率按总成交件数 / 总点击计算。
- `video_daily` 只有统计周期恰好等于所选窗口时才展示；否则视频区域显示无该口径数据的空态。
- 数据库连接或查询失败仍返回安全 `503`；缺失日期则正常 `200` 且 `available=false`，由前端展示空态。

## 验收

1. API 支持 `GET /api/boss/douyin?range=day|7d|30d&end_date=YYYYMMDD`。
2. `20260722` 的 7 天、30 天窗口返回聚合数据；`20260622` 的 7 天窗口返回 `available=false`。
3. BOSS 页面有日期选择器和三种范围按钮；选择无数据日期显示空态。
4. 单元测试、Web 构建与 lint 通过；更新 API、重打包并覆盖 `D:\TUODIAO`，从桌面代理核验真实响应。

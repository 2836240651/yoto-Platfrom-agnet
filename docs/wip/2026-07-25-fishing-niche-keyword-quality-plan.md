# 小众渔具词双侧质量实施计划

**目标：** 任意已收录或可精确查询的渔具词均执行视频、商品双侧采集；只对已采集且相关的结果进行 LLM 分析，并如实呈现空侧诊断。

**架构：** 精确种子词始终优先。静态渔具词典只提供标准词和最多两个窄变体；肉机按查询血缘逐条采集并相关性过滤；分析器只接受本次有效原始词，LLM 不可用时不伪装为已完成的深度分析。

**五词验收集：** `反底钓`、`海夕8号`、`筏轮微铅`、`钨坠`、`波爬`。

## 任务

### 1. 查询计划契约
- 为五词写参数化测试：精确词保留、扩词不超过两个、不得出现泛词、每条扩词保留知识库来源。
- 补未命中词测试：仅精确查询，记录知识库未命中，不生成猜测扩词。

### 2. 双侧采集质量门槛
- 为每个查询词保存视频/商品原始数、解析数、过滤数及错误状态。
- 仅允许与查询词或知识库标准词相关的行进入结果；不允许视频商品互相借词填充。
- 空侧生成明确的 `no_data` 结论和诊断，不产生虚假词卡。

### 3. LLM 分析门槛
- 在调用前只传有效原始词和查询血缘。
- 校验返回词、侧别、证据和操作建议均符合本次数据集；不合格输出触发一次默认可用模型重试。
- 两次失败后保留采集证据并标记分析未完成，而非输出粗糙的“交付报告”。

### 4. 五词验证与审查
- 先运行单元/契约测试。
- 再从本地已登录肉机提交五个同参数真实任务，保存不含 Cookie/Token 的诊断。
- 按查询计划、双侧覆盖、相关性、LLM 卡片质量、空侧说明五项审查，补充词典或规则后复验。

## 约束
- 禁止静默降级到 `钓鱼`、`渔具`、`鱼竿` 等泛词。
- 禁止编造未采集关键词或将扩词结果标为种子词精确实测。
- 不记录或提交 Cookie、Token、API Key、密码。
- 不修改现有未提交的发布包/肉机二进制文件。

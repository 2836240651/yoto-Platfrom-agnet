# 基准采集：抖音关键词智能体 · 界面与交互

> 采集日期：2026-07-22  
> 用途：为 React + FastAPI 产品页提供 UI/UX 基准，非技术实现文档。

---

## 1. 对标产品形态

| 产品类型 | 代表 | 运营怎么用 | 可借鉴 |
|---------|------|-----------|--------|
| 数据平台 | 蝉妈妈、巨量算数、飞瓜 | 选品类 → 看热搜/关联词 → 导出 | 关键词卡片、优先级 P0/P1/P2、趋势箭头 |
| 作战报告页 | 内部 HTML 潜词作战页 | 打开链接 → 看摘要 → 按卡片执行 | 顶部统计、对比块、行动建议、种子词警示 |
| 智能体平台 | Dify、Coze Bot | 选应用 → 填参数 → 等结果 | 任务状态、进度、历史列表 |
| 本项目目标 | 抖音词分析智能体 | **选任务模板 → 填种子词 → 确认 → 看报告** | 确定性流程 + 卡片化结果 |

**结论：** 不做「聊天框随便问」，做 **任务驱动 + 报告交付**，视觉参考数据平台的卡片和优先级体系。

---

## 2. 核心用户流程（运营视角）

```
首页（概览）
  → 新建分析（填种子词 + 勾选视频词/商品词）
  → 确认参数卡片
  → 任务执行中（步骤进度：采集 → 扩展 → 打分 → 报告）
  → 结果页（四 Tab：视频热搜 / 视频潜力 / 商品热搜 / 商品潜力）
  → 导出 Excel / 查看历史
```

运营全程 **不需要** 看到：Agent、MCP、LangGraph、prompt。

## 3. 页面基准（从作战报告页提炼）

### 3.1 顶部摘要区

- 4 个数字指标：分析词数、视频样本、商品 SKU、本周必做 P0 数
- 标签行：种子词、数据周期、筛选条件、数据警示（如「热搜榜无长尾指数」）

### 3.2 关键词卡片（单条）

每条词一张卡，包含：

| 区块 | 内容 |
|------|------|
| 标题行 | 关键词 + 优先级徽章（P0/P1/P2）+ 趋势（↑升 / →平 / ↓降） |
| 理由 | 一句话：为什么入选 |
| 指标格 | 热度、关联视频数、30天销量、增速等 3~4 个数字 |
| 迷你柱图 | 近几周趋势（可选，V1 可省略） |
| 证据 | 2~3 条 bullet，来源说明 |
| 行动建议 | 「本周建议拍 3 条 #xxx 话题片」 |

### 3.3 色彩与组件

| 元素 | 色值/样式 |
|------|----------|
| 主色 | `#0d9488`（青绿） |
| 背景 | `#f4f6f9` |
| P0 | 绿 `#16a34a` |
| P1 | 橙 `#d97706` |
| P2 | 灰 `#94a3b8` |
| 上升 | 绿底 |
| 下降 | 红底 `#dc2626` |
| 卡片 | 白底、圆角 14px、浅阴影 |

### 3.4 警示块

- 绿色 alert：赛道判断、和对照词对比
- 橙色 alert：种子词过长勿当潜词、数据局限说明

## 4. 任务状态基准

| 状态 | 运营看到 | 系统行为 |
|------|---------|---------|
| `pending` | 排队中 | 等待执行 |
| `confirming` | 参数确认卡片 | 展示将执行的步骤 |
| `running` | 进度条 + 当前步骤名 | 调 Agent/MCP |
| `completed` | 完整报告页 | 结果可导出 |
| `failed` | 人话错误 + 重试按钮 | 记录 dead_end |

步骤名（固定）：`采集数据` → `扩展联想词` → `打分分类` → `生成报告`

---

## 5. 不做的事（V1）

- 自由对话聊天
- 用户改 Skill / 调 prompt
- 原始 JSON / 日志暴露给运营
- 多平台（先只做抖音词分析一个 Skill）
